# NEXORA

Sitio editorial en español sobre inteligencia artificial, videojuegos y tecnología.

## Estructura

- `index.html`: página principal.
- `styles.css`: diseño adaptable a móvil y escritorio.
- `script.js`: navegación móvil y año del pie de página.
- `favicon.svg`: icono del sitio.

## Desarrollo local

Abre `index.html` en un navegador o usa cualquier servidor estático local.

## Publicación gratuita con Cloudflare Pages

1. En Cloudflare, crea un proyecto de Pages conectado a este repositorio.
2. Selecciona la rama `main`.
3. Para este sitio estático, deja vacío el comando de compilación.
4. Usa `/` como directorio de salida.
5. Publica y elige un subdominio disponible `*.pages.dev`.

## Estado actual

Primera versión visual. Los bloques de artículos son ejemplos editoriales y deben sustituirse por contenido original completo antes de solicitar monetización. No hay aún CMS, autenticación, base de datos ni integración de anuncios.
